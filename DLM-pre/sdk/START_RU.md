# Самостоятельный комплект DLM для Windows x64

Откройте `DLM-Shell.cmd`. Команда `dlm` и все библиотеки доступны в этой
командной строке без дополнительных настроек. Рабочая папка — `projects`.

```bat
dlm --version
dlm check Hello\main.dlm
dlm run Hello\main.dlm
dlm build Hello\main.dlm -o Hello\Hello.exe
Hello\Hello.exe
```

Для первого проекта также есть `projects\Hello\Build.cmd` и `Run.cmd`.
Для своего приложения создайте отдельную папку в `projects` и файл `main.dlm`.
Можно вызывать `dlm.cmd` по полному пути из другой рабочей папки.

Комплект содержит готовый `bin\dlm.exe`, модули `lib`, переносимый C-компилятор
`toolchain\mingw64`, примеры и документацию. Для обычной разработки из этого
комплекта Cargo, Rust, Visual Studio, WSL и Интернет не нужны. Сохраняйте всю
структуру папки при переносе на другой компьютер Windows x64.

Библиотеки `.dlm` загружаются при проверке/сборке и компилируются вместе с
приложением. Готовое приложение запускается как Windows EXE. Отдельные
приложения могут обращаться к данным и внешним ресурсам, указанным их кодом.

Фактическая версия записана в `VERSION.txt`. Параметры сборки и пройденная
проверка первого приложения записаны в `build-info.json`. Для обновления
самого компилятора заново запустите исходный сборщик на обновлённых исходниках.
