# Калькулятор на DLM

Исходники оконного калькулятора для **DLM 0.130.0 и новее**, Windows x64.
Вся логика, интерфейс и цикл событий написаны на DLM. Окно создаётся через
стандартную библиотеку DLM; браузер и отдельная GUI-библиотека не нужны.

## Сборка и запуск

1. Распакуй **содержимое ZIP** прямо в `M:\users\Ark\Desktop\DLM\DLM-CALCULATOR`.
   Файл `main.dlm` должен находиться непосредственно в этой папке.
2. Убедись, что рядом находится готовый SDK: `M:\users\Ark\Desktop\DLM\DLM-OUT`.
3. Дважды нажми **Build.cmd**. Скрипт проверит тесты и создаст `Calculator.exe`.
4. Запускай **Calculator.exe** или **Run.cmd**. При первом запуске `Run.cmd`
   сам выполнит сборку, если EXE ещё нет.

Rust устанавливать и исходники компилятора пересобирать не требуется.
Используются компилятор, стандартные библиотеки и GCC из готового `DLM-OUT`.
Для отдельной проверки тестов есть **Test.cmd**.

Если SDK находится в другом месте:

```powershell
.\Build.ps1 -SdkPath 'D:\DLM-OUT'
```

Либо задай переменную окружения `DLM_SDK`. Для быстрой повторной сборки после
уже пройденных тестов: `.\Build.ps1 -SkipTests`. Лог сборки: `build\build.log`.
Перед повторной сборкой закрой работающее окно калькулятора.

После сборки `Calculator.exe` можно скопировать в другую папку и запускать
самостоятельно на Windows x64: DLM, Rust, GCC и папка `assets` для его работы
не нужны. Иконка и манифест встроены в EXE, системные шрифты берутся из Windows.

## Возможности

- Сложение, вычитание, умножение, деление; повторное нажатие `=`.
- Десятичная точка и запятая, смена знака, проценты, квадрат, корень, `1/x`.
- `C` сбрасывает вычисление; `CE` очищает текущий операнд; `⌫` удаляет цифру.
- Память: `MS`, `MR`, `MC`, `M+`, `M−`. Кнопка `C` сохраняет память и историю.
- История хранит последние восемь результатов в рамках сеанса. В окне показаны
  три последних; нажатие строки возвращает её результат в расчёт.
- Обработка деления на ноль, корня из отрицательного числа и переполнения.
  Новая цифра, `C` или `CE` позволяют продолжить работу после ошибки.
- Мышь, клавиатура и изменение размера окна. Начальный масштаб можно задать
  командой `Run.cmd --scale 125` — от 50 до 200 процентов.

Это обычный последовательный калькулятор: `2 + 3 × 4 = 20`.
При `200 + 10 % =` получится `220`, при `200 × 10 % =` — `20`.
Память и история очищаются при закрытии приложения, файлы с расчётами не создаются.

Арифметика использует Float64. Результаты выводятся с округлением до 12 значащих
цифр, внутреннее значение сохраняет полную точность Float64. Ввод ограничен
16 цифрами. Большие и очень малые результаты отображаются в научной записи.
Расчёты с Float64 могут иметь погрешность; это не десятичная финансовая арифметика.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `0–9`, `.` или `,` | Ввод числа |
| `+`, `-`, `*`, `/`, `%` | Арифметика |
| `Enter` или `=` | Результат; повтор последней операции |
| `Esc` или `C` | Сброс вычисления |
| `Delete` | CE |
| `Backspace` | Удаление последней цифры |
| `N` | Смена знака |
| `R` | Квадратный корень |
| `S` | Квадрат |
| `I` | Обратное число |
| `H` | Очистка истории |

Буквенные сочетания работают в английской раскладке. Кнопки доступны при любой
раскладке. Память управляется кнопками в окне.

## Исходники

| Файл | Назначение |
| --- | --- |
| `main.dlm` | Точка входа и параметры запуска |
| `calculator/core.dlm` | Вычисления, ввод, память и история |
| `calculator/view.dlm` | Векторный интерфейс и определение нажатой кнопки |
| `calculator/window.dlm` | Окно, события и перерисовка |
| `tests.dlm` | Проверки арифметики и переходов состояния |
| `ui-tests.dlm` | Проверки мыши, масштаба и перерисовки без открытия окна |
| `preview.dlm` | Генерация PNG интерфейса без открытия окна |
| `assets/` | Иконка, манифест DPI и ресурсы Windows |

`Build.cmd` проверяет тесты и собирает приложение. Архив содержит исходники;
готовый Windows EXE создаётся локально твоим SDK. Исходники и отрисовка проверены
в Linux; фактический запуск окна Win32 нужно выполнить на твоём Windows.
