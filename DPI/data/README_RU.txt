Сюда можно скопировать существующие hostlist и IPSet из старой программы.
Укажите реальные файлы в интерфейсе или config.ini. Исходный src.zip содержит
только код; пользовательские списки и AWS JSON в нём отсутствуют.
Доменные правила: example.org, *.example.org, .example.org, строки hosts.
IPv4/IPv6: отдельный адрес или CIDR. Пустые строки и комментарии # / ; пропускаются.
