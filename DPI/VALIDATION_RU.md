# Проверка 2.2 — исходники для локальной сборки

В архиве нет новых EXE, объектных файлов и сгенерированного C. Build-And-Run.cmd
соберёт четыре программы у пользователя и запишет их хеши в build-local.json.

Проверки выполнялись DLM 0.133.0 из переданного SDK:

- Прежние core-тесты TLS/HTTP/QUIC, списков, checksum, потоков и ручного режима.
- Adaptive-тесты с AddressSanitizer/UndefinedBehaviorSanitizer.
- Automatic-тесты DNS/обычных сайтов, SYN, приватных адресов и исключения старого
  RST после лимита cover; ожидания обновлены для адресного QUIC auto.
- 32 комбинации фильтра захвата.
- Новый evolution_checks: кодек генома и профиля, недопустимые диапазоны,
  2000 мутаций, сохранение элиты, воспроизводимость от seed и отсутствие
  дубликатов; реконструкция исходного TCP payload для 80 геномов, IPv4/IPv6,
  sequence около переполнения; проверка checksum и старого sequence cover;
  адресная область QUIC; отсутствие ложных 100% при нулевой атрибуции;
  корректность сохранённой оценки; ClientHello с SNI во втором сегменте.
  Этот набор выполнен с ASan/UBSan.
- Три повтора эволюционных тестов через экспортированный native ABI:
  код 0, native-ошибок нет, живых выделений DLM после каждого вызова — 0.
  Проверка LeakSanitizer не заявляется.
- Для четырёх приложений получен C backend output; он скомпилирован в Windows
  x64 object files. Для движка, GUI и HTTP-пробы выполнены static assertions
  размеров/offsets с настоящими Windows headers, включая WinDivert address,
  WinHTTP connection info и структуры файловых диалогов.
- PowerShell parser проверил все сценарии. В изолированных тестах выполнены
  атомарная замена файлов, quoting Windows-путей, положительный/отрицательные
  DOM fixtures, UUID и socket-фильтрация преобразований, сохранение предыдущего
  active.profile при неподтверждённом результате и выбор файлов сборщиком.

Не выполнялись: работа WinDivert, GUI, UAC, реальные headless Chrome/Edge,
полный цикл Train.ps1 и сборка скриптом в настоящей Windows. Их проверит локальный
запуск. Тесты кода и C-компиляция не считаются доказательством обхода ТСПУ.
Нет подтверждённого процента доступности YouTube или воспроизведения видео
для версии 2.2. GUI показывает только фактически измеренные пробы и их границы.

Перед выдачей ZIP проверяется чтением всех записей, сравнением с изменёнными
файлами и отсутствием EXE/бинарных сборочных артефактов.
