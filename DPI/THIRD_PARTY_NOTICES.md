# WinDivert 2.2.2-A

WinDivert by Basil (basil00) and contributors; upstream copyright notices
are retained in the supplied header and corresponding source archive.
The included WinDivert distribution is unmodified. Upstream offers LGPL v3
or GPL v2; this package uses the LGPL v3 option. Full upstream licensing text
is in `vendor/WinDivert/LICENSE.txt`.

- Official project: https://reqrypt.org/windivert.html
- Binary distribution: https://github.com/basil00/WinDivert/releases/download/v2.2.2/WinDivert-2.2.2-A.zip
- Corresponding source distribution: https://reqrypt.org/download/WinDivert-2.2.2-Source.zip
- Source repository: https://github.com/basil00/WinDivert/tree/v2.2.2

Files supplied: `WinDivert.dll`, `WinDivert64.sys`, `vendor/WinDivert/WinDivert.lib`,
`vendor/WinDivert/windivert.h`, upstream license and corresponding source ZIP.
The library is dynamically linked; a compatible replacement DLL may be placed
next to NoDPI.exe. No restriction on reverse engineering for debugging library
modifications is added. The Windows driver remains subject to OS signing rules.
